# Tokyo Drift — Godot

Neon-Tokyo arcade drift racer, rebuilt in **Godot 4** with real asset packs.
City first, then circuit: a long track through a designed city, not a full open world.

## Status (2026-09-18)

- City-first planning package in `docs/city-design/` (2D plan, real-meter layout, camera angles, scene design)
- Godot 4.7 project skeleton (`project.godot`, `scenes/`, `scripts/`)
- Asset shortlist in `ASSET_SHORTLIST.md`; $0 prototype set tracked in `assets/prototypes/SOURCES.md`
- Art reference in `assets/art-reference/` — consult during 2D design, storyboarding, mocks, 3D model design

## Docs

- `GAME_DESIGN.md` — game design
- `docs/city-design/CITY_LAYOUT.md` — rebuild spec in world meters
- `docs/city-design/SCENE_DESIGN.md` — district identities, lighting, props
- `docs/city-design/METHODOLOGY.md` — the build doctrine (2D first, sightline-driven, build only what the camera sees)
